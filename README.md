# SPDA Risk Analysis
Este programa realiza a análise de risco de SPDA e determina o nível de proteção necessário com base nos critérios fornecidos.

## Instruções de Uso
1. Clone este repositório.
2. Execute o arquivo `main.py`.
3. Forneça os parâmetros de probabilidade e impacto.
4. Veja os resultados na tela.

## Estrutura do Projeto
- `main.py`: Script principal.
- `risk_calculator.py`: Funções para cálculo de risco.
- `protection_level.py`: Funções para determinar o nível de proteção.
- `README.md`: Informações sobre o projeto.
